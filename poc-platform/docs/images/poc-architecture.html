Where it runs
  • One laptop, ./run.sh

  • No container, no deploy, no CI

Sized for a handful of reviewers, not a rollout.
POC platform — poc-platform/, FastAPI, ~2.3k LOC, localhost only

What this POC cannot be used to conclude
Nothing about security — identity is a header, so any caller can be any role
Nothing about integration effort — no adapter has been written or tested
Nothing about "app #4 in days" — no toolkit is shared between the apps yet
Nothing about load, uptime or cost — one process per app, SQLite, no CI, no monitoring
Nothing about compliance — no threat model, pen test, DLP or retention
It does evidence: one URL and one identity across unrelated stacks, per-app RBAC from a single persona choice, governance enforced by code, and a full workflow a reviewer can actually click through.
